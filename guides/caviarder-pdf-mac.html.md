# Comment caviarder un PDF sur Mac sans l’envoyer sur Internet ?

> Sur Mac, vous pouvez caviarder un PDF sans l’envoyer sur Internet avec Aperçu, l’application livrée avec macOS. Affichez la barre d’outils d’annotation, choisissez l’outil « Sélection du caviardage », puis sélectionnez le texte à masquer. D’après [Apple](https://support.apple.com/fr-fr/guide/preview/prvw11580/mac), la correction reste modifiable tant que le document est ouvert et devient permanente une fois le document fermé. Apple ne précise pas si le texte est effacé du fichier : travaillez sur une copie, puis vérifiez que le texte masqué ne peut plus être sélectionné ni retrouvé.

## Pourquoi caviarder sur son Mac plutôt qu’en ligne ?

Beaucoup d’outils en ligne reçoivent votre fichier sur leurs serveurs pour le traiter. Pour un bulletin de salaire ou une pièce d’identité, c’est une copie de plus hors de votre contrôle. Aperçu est une application installée sur votre Mac : elle ouvre et modifie le fichier sur place. C’est un constat général, la page d’Apple citée ici n’en parle pas.

## Comment caviarder un PDF avec Aperçu, pas à pas ?

1. Dupliquez le fichier et ouvrez la copie dans Aperçu : d’après [Apple](https://support.apple.com/fr-fr/guide/preview/prvw11580/mac), la correction devient permanente à la fermeture.
2. Affichez la barre d’outils d’annotation, si elle n’est pas déjà visible.
3. Choisissez l’outil « Sélection du caviardage ». C’est le nom que lui donne le guide d’Aperçu pour macOS 27.
4. Sélectionnez le texte à masquer. Recommencez pour chaque numéro.
5. Fermez le document, puis faites les vérifications décrites plus bas.

## Quelles sont les limites de l’outil d’Aperçu ?

- [Apple](https://support.apple.com/fr-fr/guide/preview/prvw11580/mac) décrit l’outil ainsi : « Sélectionnez du texte pour le masquer. » Sa page ne dit pas que le texte est retiré du fichier, d’où les vérifications plus bas.
- Il s’applique à du texte que l’on peut sélectionner. Apple ne décrit pas son usage sur un PDF scanné, où le texte est une image.
- D’après Apple, si le PDF contient une table des matières, les entrées qui renvoient au texte caviardé ne sont pas supprimées.
- Vous repérez vous-même chaque numéro, sur chaque page de chaque document.

## Dessiner un rectangle noir, est-ce pareil ?

Non. Une figure dessinée par-dessus le texte le recouvre sans le retirer : le texte peut rester dans le fichier, où il se sélectionne et se copie encore. C’est un constat technique général, que la page d’Apple ne traite pas. Utilisez l’outil de caviardage, puis vérifiez.

## Comment vérifier que le texte a bien disparu ?

1. Rouvrez le fichier caviardé.
2. Essayez de sélectionner la zone masquée et de copier son contenu.
3. Cherchez le numéro masqué avec Commande + F.
4. Si le texte se copie ou se retrouve, n’envoyez pas le fichier. Si rien ne se copie et que la recherche ne trouve rien, le texte ne se lit plus par ces moyens.

## Et pour une photo ou un scan ?

Pour une image, [Apple](https://support.apple.com/fr-fr/guide/preview/prvw11580/mac) décrit l’outil « Sélection rectangulaire », qui sélectionne une zone pour la copier ou la supprimer. Pour un PDF scanné, sa page ne décrit pas de méthode. Dans les deux cas, vérifiez le résultat avant d’envoyer : voir [ce qu’on peut masquer sur ses pièces](https://monsieurdossier.com/guides/masquer-informations-dossier-location.html).
