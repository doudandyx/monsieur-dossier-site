# Monsieur Dossier — site

Site de [monsieurdossier.com](https://monsieurdossier.com), publié avec GitHub Pages depuis la branche `main`.

- `index.html` : la page d'accueil (français et anglais) ; `fonctionnalites.html`, `contact.html`, `dossierfacile.html`, `mentions-legales.html` : les autres pages.
- `site.css` : la feuille de style commune à toutes les pages.
- `DESIGN.md` : les règles de design du site (couleurs, typographie, composants, règles de code).
- `fonts/` : les polices, servies par le site (Bricolage Grotesque, Inter, JetBrains Mono, licence OFL). Aucun appel à Google Fonts.
- `CNAME` : le nom de domaine.
- Les versions de l'application à télécharger sont publiées dans les *Releases* de ce dépôt, sous le nom `MonsieurDossier.dmg`.
