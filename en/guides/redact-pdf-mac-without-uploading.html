How do I redact a PDF on a Mac without uploading it?

On a Mac, you can redact a PDF without uploading it by using Preview, the app that comes with macOS. Show the Markup toolbar, choose the Redaction Selection tool, then select the text to hide. According to Apple, you can still change the redaction while the document is open, and it becomes permanent once the document is closed. Apple does not say whether the text is erased from the file: work on a copy, then check that the hidden text can no longer be selected or found.

Updated on 24 November 2026

Why redact on your Mac instead of online?

Many online tools receive your file on their servers to process it. For a payslip or an identity document, that is one more copy out of your control. Preview is an app installed on your Mac: it opens and edits the file in place. This is a general observation, which the Apple page cited here does not cover.

How do you redact a PDF with Preview, step by step?

  1. Duplicate the file and open the copy in Preview: according to Apple, the redaction becomes permanent on closing.
  2. Show the Markup toolbar, if it is not already visible.
  3. Choose the Redaction Selection tool. That is its name in the Preview guide for macOS 27.
  4. Select the text to hide. Repeat for each number.
  5. Close the document, then run the checks described below.

What are the limits of Preview’s tool?

  • Apple describes the tool this way: “Select text to remove it from view.” Its page does not say that the text is removed from the file, hence the checks below.
  • It applies to text that can be selected. Apple does not describe using it on a scanned PDF, where the text is an image.
  • According to Apple, if the PDF has a table of contents, the entries that link to redacted text are not removed.
  • You find each number yourself, on every page of every document.

Is drawing a black box the same thing?

No. A shape drawn over the text covers it without removing it: the text can stay in the file, where it can still be selected and copied. This is a general technical observation, which Apple’s page does not cover. Use the redaction tool, then check.

How do you check that the text is really gone?

  1. Reopen the redacted file.
  2. Try to select the hidden area and copy its content.
  3. Search for the hidden number with Command + F.
  4. If the text can be copied or found, do not send the file. If nothing can be copied and the search finds nothing, the text can no longer be read by these means.

What about a photo or a scan?

For an image, Apple describes the Rectangular Selection tool, which selects an area to copy or delete. For a scanned PDF, its page describes no method. In both cases, check the result before you send it: see what you can hide on your documents.
